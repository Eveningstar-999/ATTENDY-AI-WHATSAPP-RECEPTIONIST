# AI Agent Workflow

## Main Workflow

Customer
↓
WhatsApp
↓
Attendly AI
↓
Understand request
↓
Determine required action
↓
Answer or perform action
↓
Save customer/lead information
↓
Book appointment if required
↓
Follow up automatically

## Example

Customer:

"I want to book an appointment for tomorrow."

Attendly:

1. Understands the request
2. Identifies the required appointment type
3. Checks availability
4. Requests missing customer information
5. Creates the appointment
6. Saves the customer/lead
7. Sends confirmation
